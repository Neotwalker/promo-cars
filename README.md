# promo-cars

Одностраничный промо-сайт автомобильного импорта, собранный по референсу из screen recording.

## Что реализовано

- полноэкранный hero и фиксированная навигация;
- блок преимуществ со sticky-композицией;
- scroll-секция «Как мы работаем» с последовательной сменой карточек;
- сетка привезённых автомобилей;
- интерактивный мини-квиз расчёта;
- блок о компании, отзывы, FAQ и финальный CTA;
- адаптив для планшета и телефона;
- reduced-motion режим.

## Запуск

Сборка не нужна. Откройте `index.html` или запустите любой статический сервер:

```bash
python3 -m http.server 8080
```

Файлы проекта: `index.html`, `styles.css`, `app.js`.
