# NEXROUTE AUTO — promo-cars

Landing page project for NEXROUTE AUTO.

## Structure

- `ui-kit/` — shared UI foundation.
- `prototype/` — frozen UX prototype and state specimens.
- `live/` — current approved visual implementation, built on the shared UI-kit foundation.

## Local preview

```bash
python3 -m http.server 8080
```

- Live: `http://localhost:8080/live/`
- UI kit: `http://localhost:8080/ui-kit/`
- Prototype: `http://localhost:8080/prototype/`
- States: `http://localhost:8080/prototype/states.html`
